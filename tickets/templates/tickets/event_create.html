Event Information

Event Name: The name of the event (e.g., "Familiar Faces", "Summer Festival").

Venue: Select the venue where the event takes place. If the venue doesn't exist yet, create one first.

Start Date / Time: The date (required) and time (optional) the event starts.

End Date / Time: Optional end date and time. End date is required if end time is provided.

Description: Optional description or notes about the event.

Capacity: Optional total ticket capacity for the event.

Ticket link: Optional URL to the ticket purchase page.

Parking Info: If your organization uses the Parking Info custom field, select from the dropdown (e.g. Street parking, Lot available, No parking, See venue).

Talent lineup: Optional list of performers or DJs; use Order to set display order.

Note: Each event must have a unique combination of name and date. You can also create events automatically by uploading a CSV file.
