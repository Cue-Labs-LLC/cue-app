Format Configuration Help

Column Mapping Format:

{
  "order_number": ["order_id", "order_number"],
  "order_date": ["date", "order_date"],
  "customer_email": ["email", "customer_email"],
  "customer_name": ["name", "customer_name"],
  "event_name": ["event", "event_name"],
  "event_date": ["event_date", "show_date"],
  "venue": ["venue", "location"],
  "ticket_type": ["ticket_type", "tier"],
  "price": ["price", "ticket_price"],
  "quantity": ["quantity", "qty"]
}

The system will try each column name in the array until it finds a match in the CSV file.

Tier-Based Pricing:

When enabled, you can define multiple pricing tiers per ticket type with allotments. Orders are assigned to tiers based on order date (first-come-first-served) until tier capacity is reached. Note: Tier-based pricing can only be enabled when manual pricing is required.
